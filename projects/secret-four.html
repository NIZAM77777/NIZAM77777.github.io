Secret Four

Secret Four is a strategic 2D board game built with Unity and C#. The game combines turn-based board play with a directional mechanic and online human-vs-human multiplayer.

UnityC#2DMultiplayerNetworkingAndroid

Gameplay

Players take turns making board moves and selecting directions according to the game's rules. The objective is to use positioning and direction choices to create a winning board state.

Online Multiplayer

The multiplayer implementation uses a room-based flow so two players can create or join the same room and play from separate devices. Core state synchronization includes player identity, player names, skins, turns, coin placement, direction selection, round progression and gameplay actions.

Development Focus

  • Room creation and room joining
  • Turn and ownership synchronization
  • Shared game-state management
  • Round and result transitions
  • Player-name and skin synchronization
  • Mobile-friendly UI and gameplay flow

Current Status

The core online gameplay and synchronization systems are implemented. Remaining work focuses on UI polish, final testing and bug fixing before release.
